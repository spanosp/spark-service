# spark-service

A private, single-user app that connects its owner's own Google account to the
owner's personal automation. It is not offered to the public.

## What it does

- Reads the owner's Google Contacts, read-only, to recognise people the owner
  already knows. It never adds, changes or deletes contacts.
- Creates files in the owner's Google Drive and updates only the files it
  created itself. It cannot see any other file in the Drive.
